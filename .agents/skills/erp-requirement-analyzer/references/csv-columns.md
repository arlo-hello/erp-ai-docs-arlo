# CSV 列参考

## 需求池 CSV 列名

飞书多维表格导出后，列名映射如下：

| CSV 列名 | 说明 | 分析用途 |
|---------|------|---------|
| 需求名称 | 需求标题 | 关键词提取、领域分类 |
| 需求类型 | 综合需求/开发需求/配置需求/数据需求/需求评估 | 类型×质量交叉分析 |
| 优先级 | 很重要很紧急/很重要非紧急/非重要很紧急/非重要非紧急 | 优先级×缺陷交叉 |
| 需求背景 | 需求背后原因 | 需求合理性评估 |
| 需求目标 | 期望达成的目标 | 验收标准提取 |
| 需求描述 | 详细描述 | 关键词提取、范围评估 |
| 期望上线日期 | 期望交付日期 | 时间线分析 |
| 提交时间 | 提交时间戳 | 月度趋势 |
| 状态 | 已完成/无需处理/待评估/需求撤回/开发中等 | 撤回率、完成率 |
| 提交人 | 需求提出者 | 需求来源 |
| 负责人 | 需求负责人 | 责任归属 |
| 计划用时（h） | 预估工时 | 投入产出比 |
| 实际用时（h） | 实际工时 | 偏差分析 |
| 偏离度 | 偏差百分比 | 估算准确度 |
| 需求关联缺陷 | 关联的缺陷列表（逗号分隔） | **追溯率核心指标** |
| 需求关联迭代 | 关联迭代 | 版本分布 |

## 缺陷 CSV 列名

| CSV 列名 | 说明 | 分析用途 |
|---------|------|---------|
| 反馈名称 | Bug 标题 | 关键词提取 |
| 反馈详细描述 | Bug 详细描述 | 根因分析 |
| 状态 | 已关闭/待排期修复等 | 缺陷状态 |
| 严重程度 | 严重/重要/一般/次要 | 严重度分布 |
| 优先级 | 高-P0/中-P1/低-P2 | 优先级分布 |
| Bug端类别 | 前端/后端/数据 | 端类别分布 |
| 发现阶段 | 第一轮测试/线上反馈/产品验收等 | 质量左移分析 |
| 缺陷类型 | 功能/界面/数据/接口/性能 | 缺陷分类 |
| 缺陷关联需求 | 关联的需求 | 追溯链 |
| 缺陷关联迭代 | 关联迭代 | 版本质量 |
