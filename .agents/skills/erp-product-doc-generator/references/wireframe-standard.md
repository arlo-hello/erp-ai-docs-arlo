# 页面线框稿生成标准

> ⚠️ **示例隔离声明**：本文档中所有事件名、字段名、表格数据、线框图等均为演示示例——禁止直接复制到真实需求输出中。真实输出必须基于实际需求分析和代码侦察结果。

> 本文件定义技能5线框图的**代码溯源 + 自检闭环**标准。需求驱动模式用技能自身产出做溯源，代码驱动模式用实际代码文件做溯源。

---

## 1. 前置输入

- **需求驱动模式**：技能1领域事件清单 + 技能3故事地图 + 本技能页面流转图 + 单据信息表
- **代码驱动模式**：前端页面代码（Vue/TSX文件） + 变更需求描述
- 两种模式都必须有可追溯的来源——每个线框图元素标注来源（事件编号/单据信息表字段）

---

## 2. 执行步骤

### 步骤1：页面类型识别

先判断每个页面的类型，在线框图前标注：

| 类型 | 识别条件 | 来源 |
|:---|:---|:---|
| 列表页 | 事件类型为"人的操作-批量"的入口 | 技能1事件清单 |
| 详情页 | 单据信息表每行必有 | 单据信息表 |
| 表单页 | 创建/编辑/新建类事件 | 技能1事件清单 |
| 弹窗 | 操作类事件的触发（单个/批量/逆向） | 技能1事件清单 |

### 步骤2：强制区域划分

每个页面划分为三个固定区域，独立分析：

- **头部区域**：页面标题、主操作按钮、搜索/筛选区
- **中部区域**：表格（列表页）、信息卡片（详情页）、表单步骤（表单页）、字段区（弹窗）
- **底部区域**：分页组件（列表页）、提交/取消按钮（弹窗/表单页）、总计信息

### 步骤3：区域内元素穷举

按区域逐行提取元素。每个元素必须显式列出完整名称——不使用"等""其他字段""..."等省略表述。

| 区域 | 提取内容 | 每项标注 |
|:---|:---|:---|
| 筛选区 | 每个筛选项的字段名、控件类型、默认值、联动条件 | 字段来源（单据信息表字段/字段设计表字段） |
| 表格区 | 每列的列名、字段名、是否可排序、特殊展示（标签/时间格式） | 字段来源 |
| 按钮区 | 每个按钮的文本、位置（工具栏/行内/底部）、显示条件、触发功能 | 事件来源（技能1事件编号） |
| 表单/详情区 | 每个字段的标签、字段名、控件类型、必填、校验规则 | 字段来源 + 校验规则来源（字段设计表） |

### 步骤4：填入标准 ASCII 线框模板

**列表页模板**：
```
页面类型: 列表页
+--------------------------------------------------+
|  [页面标题]                     [按钮1] [按钮2]    |
|  搜索: [___]  [筛选1▼] [筛选2▼]   [搜索] [重置]    |
+--------------------------------------------------+
|  ☑ | 列1     | 列2      | 列3     | 操作          |
|     | data    | data     | data    | [按钮1][按钮2] |
+--------------------------------------------------+
|  已选 N 项  [批量操作按钮]                          |
+--------------------------------------------------+
|  [分页]                          第1-20条，共200条  |
+--------------------------------------------------+
```

**详情页模板**：
```
页面类型: 详情页
+--------------------------------------------------+
|  [页面标题]                      [按钮1] [按钮2]   |
+--------------------------------------------------+
|  + 信息卡片1 --------------------------------+  |
|  | 字段1: XXX    字段2: XXX    字段3: XXX      |  |
|  +--------------------------------------------+  |
|  + 信息卡片2 --------------------------------+  |
|  | 字段4: XXX    字段5: XXX                   |  |
|  +--------------------------------------------+  |
+--------------------------------------------------+
```

**弹窗模板**（独立线框图块——不是父页面附注）：
```
页面类型: 弹窗
弹窗名称：[弹窗名称]（单个 / 批量-已选N单）
触发来源：[父页面名称] - [按钮名称]

+--------------------------------------------------+
|  弹窗标题                                         |
|                                                  |
|  字段1*: [________]                               |
|  字段2*: [下拉▼]                                  |
|  条件字段: [下拉▼]（联动: 字段2=X时显示）            |
|                                                  |
|  提示: [业务规则说明]                               |
|                                                  |
|                              [确认]  [取消]        |
+--------------------------------------------------+
```

**批量结果反馈弹窗**：
```
页面类型: 弹窗
弹窗名称：批量[操作名]结果反馈
触发来源：[父列表页] - [批量操作按钮]

+--------------------------------------------------+
|  批量[操作名]完成                                  |
|  ✅ 成功: N 单                                     |
|  ❌ 失败: M 单                                     |
|  失败明细:                                         |
|    单号XXX - 原因: [校验失败/系统异常]               |
|    单号YYY - 原因: [校验失败/系统异常]               |
|                              [确定]               |
+--------------------------------------------------+
```

**撤销确认弹窗模板** 🔴（逆向操作专用）：
```
页面类型: 弹窗（逆向确认）
弹窗名称：[撤销XX操作]确认
触发来源：[父页面名称] - [撤销/取消/撤回按钮]

+--------------------------------------------------+
|  ⚠️ 确认撤销 [操作名称]？                           |
|                                                  |
|  操作对象: [单据号/名称]                            |
|  当前状态: [当前状态]                               |
|                                                  |
|  此操作将执行以下变更:                               |
|  · [级联变更1: 如"入库单 SH-001 将被作废"]           |
|  · [级联变更2: 如"未发货库存 +100 将被释放"]          |
|  · [级联变更3: 如"将通知WMS取消该入库预报"]           |
|                                                  |
|  + 不可逆条件检查 ----------------------------+   |
|  | [✅/❌] 未开始收货 —— [通过/不通过]           |   |
|  | [✅/❌] 未触发内采链 —— [通过/不通过]         |   |
|  +--------------------------------------------+   |
|                                                  |
|  [❌条件] 提示: [已部分收货，不允许取消预报]          |
|                                                  |
|  撤销原因*: [________________] (选填)              |
|                                                  |
|                              [取消] [确认撤销]      |
+--------------------------------------------------+
```

> 🔴 撤销弹窗与普通弹窗的关键差异：
> 1. **级联影响展示**：明确列出撤销后会自动执行的所有级联操作
> 2. **不可逆条件检查**：逐条展示前置条件，不通过时显示❌并禁用确认按钮
> 3. **撤销原因**：建议提供选填的撤销原因字段（审计需要）
> 4. **确认按钮文案**：用"确认撤销"而非"确认"，与正向操作区分
> 5. **警告图标**：使用 ⚠️ 前缀暗示操作的破坏性

### 步骤5：补全结构化附表

线框图之外，每个页面必须附带两张表：

**字段表**：
| 字段名 | 说明 | 来源（事件编号/单据信息表字段） | 特殊展示/规则 |
|--------|------|-------------------------------|--------------|
| ...    | ...  | ...                           | ...          |

**按钮表**：
| 按钮名 | 位置 | 显示条件 | 触发功能 | 来源（事件编号） |
|--------|------|---------|---------|-----------------|
| ...    | ...  | ...     | ...     | ...             |

> 需求驱动模式下，"来源"列填技能1事件编号或单据信息表字段名。代码驱动模式下填代码文件:行号。

---

## 3. 自检验收清单

线框稿完成后，逐条执行自检，并在线框稿末尾附自检报告。

### 正向追溯（来源 → 线框图）
- [ ] 单据信息表中每个字段在对应详情页线框图中出现（或标注为"不在本页面展示"）
- [ ] 技能1的每个人操作事件在对应页面的按钮表中有对应按钮
- [ ] 技能1的每个批量事件有独立的批量弹窗和结果反馈弹窗
- [ ] 技能1的每个逆向事件有确认弹窗
- [ ] 字段设计表的联动逻辑已翻译为线框图中的条件显示说明

### 反向追溯（线框图 → 来源）
- [ ] 线框图和附表中的每个字段、按钮均有明确来源——无凭空捏造的元素
- [ ] 如有代码驱动模式：每个元素可追溯到代码文件:行号

### 变更标注
- [ ] 新增字段用 `+` 前缀标注，修改字段用 `*` 前缀标注
- [ ] 新增按钮用 `+` 前缀标注
- [ ] 变更点与需求描述完全对应——无额外改动

### 格式完整性
- [ ] 线框图使用 ASCII 字符绘制，三区域完整（头部/中部/底部）
- [ ] 字段表和按钮表无空白行
- [ ] 弹窗独立成块，非内嵌于父页面
- [ ] 页面清单中列出的每个页面，线框图、字段表、按钮表均已产出

---

## 4. 自检报告格式

```
## 线框稿自检报告

### 页面统计
- 页面清单 P = ___
- 线框图产出 W = ___
- W = P? [通过/未通过]

### 正向追溯
- [x] 字段覆盖率: N个单据字段中M个出现在对应线框图中（覆盖率=M/N）
- [x] 按钮覆盖率: K个人操作事件中J个有对应按钮（覆盖率=J/K）
- [x] 批量弹窗数: L个批量事件 → L个批量弹窗 + L个结果反馈（全部/缺少__个）
- [x] 逆向弹窗数: R个逆向事件 → R个撤销确认弹窗（全部/缺少__个）
- [x] 🔴 逆向弹窗专项：每个撤销确认弹窗含①级联影响展示 ②不可逆条件检查 ③确认按钮文案=确认撤销 ④⚠️警告图标（四项缺一不可）
- [x] 字段联动: 字段设计表中S条联动规则 → 线框图中标注了T条（覆盖率=T/S）

### 反向追溯
- [x] 线框图中所有元素均有来源，无凭空元素
- [x] 未追溯元素列表: [如有则列出]

### 变更标注
- [x] 新增: N个字段/N个按钮（已全部+标注）
- [x] 修改: M个字段（已全部*标注）

### 格式完整性
- [x] 全部线框图三区域完整
- [x] 字段表+按钮表均已产出且无空白行
- [x] 弹窗线框图均为独立块

### 未通过项
[如有未通过的检查项，列出并说明修正措施]
```

**如果任何一条未通过，必须立即修正并重新自检，直到全部通过。**
