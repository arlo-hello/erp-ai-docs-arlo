# Changelog — erp-product-doc-generator

> 从 v5.6 到 v9.x 的关键版本记录。当前版本号见 SKILL.md frontmatter。

- **v9.4** (2026-08-18): 输出文件名去除技能编号和阶段序号，改为纯中文文档标题；阶段顺序由技能编排表达，不再向读者暴露内部编号，也消除 `08` 前的断号观感。
- **v9.3** (2026-08-18): 输出文件改为“两位阶段编号 + 文档中文标题”，并要求文件名后半段、YAML title 和 H1 完全一致；`06-design.md` 更名为 `06-产品需求文档.md`，`08-product-design.md` 更名为 `08-产品系统设计方案.md`，全链路引用同步。
- **v9.2** (2026-08-18): 修复 v9.1 新旧口径残差——技能1事件表显式承载Fact ID、状态敏感、自动化决策；主入口统一为11维I/O与9影响+4可行评估；验证门前移事实/命名/状态/自动化检查并补齐八类Trace Ledger；技能8总体概要补一页结论、读者路线、责任矩阵，领域章节模板统一；evals补可验证断言。
- **v9.1** (2026-08-18): 新增“分析账本 / 读者交付 / 追溯附录”三层产物规则和 readability-standard；技能1/2引入事实确定性、缺口三问、PM判断链；技能4-8接入四层命名、责任边界、标准规则、运行时时间轴、Trace Ledger和切片业务结果名；修复事件类型计数、N:1聚合规则和ASCII线框模板冲突。
- **v9.0** (2026-08-18): 输出文件编号与技能编号对齐，废弃旧 `00-events.md` ~ `05-design.md` 命名。
- **v8.0** (2026-07-09): 新增「产品系统设计方案」汇总输出（技能8），按金字塔原理四层结构重组。技能3/5源头遵循 Mermaid 兼容语法。
- **v7.13** (2026-07-09): 横切关注点交付断层修复——技能6/7新增整合检查表，验证门全链路横切检查。
- **v7.12** (2026-07-09): 逆向设计断层修复——技能2+第9维可逆性，技能4逆向独立模块铁律，撤销弹窗五要素模板。
- **v7.11** (2026-07-08): 全技能「声明绕过推导」漏洞修复——所有校验点改为"逐项填表→汇总→验证"。
- **v7.10** (2026-07-08): 页面推导公式→强制五部分填表校验，杜绝 W=P=2 类绕过。

- **v7.6** (2026-07-08): 质量校验六件套——事件有效性、术语注册表、自动化三问、部分完成场景、线框图差异化。
