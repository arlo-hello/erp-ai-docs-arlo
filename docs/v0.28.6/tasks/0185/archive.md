# ERP-185 任务档案

## 需求背景

GL 区域部分目的国家存在免税政策，现有整数申报比例难以在不同 SKU 单价下稳定控制申报金额。业务进一步确认配置规则时无法预知订单 SKU，因此固定总金额改为先按产品分类分摊，再按订单实际 SKU 二次分摊。

## 方案概述

以 `ERP-SLICE-ORD-001` 交付两类独立节点。Q8 已撤回，固定金额模式从配置、计算、履约商品展示到推仓载荷统一使用 USD，不沿用履约行原币种。固定总金额支持多个有序分类分摊条件组，执行首个完整匹配组；全部条件组未匹配时整体失败并抛出异常。

## 影响范围

- 直接影响：workflow 条件配置、履约动作、履约行申报值、拆单换仓、推仓与异常处理。
- 复用能力：现有 AND/OR 条件组、仓库—物流渠道数据源、履约行 `declared_value` 与履约异常机制。
- 明确不做：目的国免税阈值主数据、自动税则判断、已推仓履约单原地改值。

## 沉淀记录

2026-11-04 完成首版需求决策关闭。2026-11-06 撤销 SKU 预配置并补充两级分摊、递归子分类、结果回写与0值推仓中断；随后撤回 Q8，将固定金额全链路统一为 USD。2026-11-07 明确 pcs 与销售价浮动除不尽时均截断。2026-11-10 增加有序分类分摊条件组、首个完整匹配与全组未命中异常，并确认异常文案为“{履约单号}履约单不符合固定申报金额配置条件，请检查”；销售价浮动公式更正为分类内按 SKU 行销售金额占比分配分类固定金额，再除以 SKU 销售数量得到单件申报金额；申报比例仅新增一位小数精度，填写范围及既有边界校验不调整。
