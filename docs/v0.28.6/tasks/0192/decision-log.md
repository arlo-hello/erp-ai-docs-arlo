## 2026-11-09 第三轮范围调整

| 决策 | 结论 | 状态 |
|---|---|---|
| 合并资格 | 所选采购发货单必须采购主体一致、原目的仓库（或收货仓库）一致；供应商允许不同。进入预报页后最终入库仓不锁定。 | 已关闭 |
| 目的主体与中转 | 合并预报支持修改目的主体所属系统、目的主体、是否中转；表单校验和后续自动链复用普通预报。 | 已关闭 |
| 聚合计算 | 数量、重量、体积等可加总数据按来源求和；价格、币种、核算维度、供应商、采购/发货来源逐行保留。 | 已关闭 |
| 合并预报商品行供应商 | 合并预报页“产品明细”每条来源商品在 SKU 下展示“供应商：名称”。 | 已关闭 |
| 入库详情供应商 | 基本信息展示全部供应商并保留省略、悬浮规则；产品明细的入库明细在 SKU 下展示来源供应商。 | 已关闭 |

### Q6 最终确认

“仓库一致”比较发货单原数据中的目的仓库（或收货仓库）；进入合并预报页后不锁定仓库，仍允许用户修改最终入库仓库。列表资格按原目的仓库校验，最终采购入库单和库存归属按本次预报填写的最终入库仓库执行。
