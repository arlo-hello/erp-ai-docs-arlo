# ERP-167 任务档案

## 需求背景

商业实体作为基础主数据承载主体、联系人、账户、多角色与供应商账期。现状已有部分后端能力，但实体类型与角色混用、停用选择边界、删除引用保护、权限和并发控制尚未形成一致闭环。

## 方案概述

以 `ERP-SLICE-PLAT-001` 交付商业实体主数据闭环；`entity_type` 降为数据库兼容字段；历史业务采用快照且不回写；停用只影响新业务选择；任何业务引用均阻止删除。

## 影响范围

- 直接影响：商业实体列表、详情、维护、启停、删除、权限、查询偏好。
- 间接影响：采购、订单、库存、财务的新业务候选与历史快照读取契约。
- 明确不做：上下游业务流程改造、历史单据批量回写、自定义角色和文件上传。
