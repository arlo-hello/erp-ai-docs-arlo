# ERP-210 任务档案

## 需求背景

样机出库依赖人工导出、补录、导入、建单和推仓，单量增加后重复操作成为效率瓶颈。[来源：ERP-210 业务背景]

## 方案概述

ERP 接收并记录全部已审批样机申请，通过样机出库 Workflow 自动匹配和推仓；Workflow 未命中或推仓异常时回传样机系统并写入一次飞书快照；正常流程不写飞书。样机系统负责取消和编辑的未出库校验，ERP 收到请求后取消关联单据链。系统联调保证不存在“推送后 ERP 接收失败且可识别”的业务分支。[来源：当前飞书 PRD §1-§4，revision 178]

## 影响范围

- 订单域：外部申请接收、幂等、自动办理、取消联动和编辑联动。
- 库存域：样机出库单、出库流水、推仓和关联单据链撤销。
- 平台域：Workflow 定义扩展和飞书异常快照。
