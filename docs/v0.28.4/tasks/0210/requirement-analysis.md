# ERP-210 需求分析

## 1. 需求范围

| 类型 | 范围 | 结论 | 来源 |
|---|---|---|---|
| 包含 | ERP 接收 | 接收并记录样机系统推送的全部已审批样机申请 | ERP-210 需求拆解第 2、5 条 |
| 包含 | Workflow | 新增样机出库触发器、条件和动作，接收后自动匹配 | ERP-210 需求拆解第 1、2 条 |
| 包含 | 自动推仓 | Workflow 命中后推仓；未命中或推仓异常时结束本次自动办理 | ERP-210 需求拆解第 2 条 |
| 包含 | 异常闭环 | 可识别异常回传样机系统并写入一次飞书异常快照 | ERP-210 需求拆解第 2、4 条；确认 D1、D3、D4 |
| 包含 | 取消校验 | 按关联样机出库单是否已有实际出库决定允许或拒绝取消 | ERP-210 需求拆解第 3 条 |
| 不包含 | 样机系统内部功能 | 不描述样机系统页面、字段及审批实现 | ERP-210 范围限定 |
| 不包含 | 正常单据飞书同步 | 正常接收、命中、推仓和出库结果均不写飞书 | 确认 D1、D3、D4 |
| 不包含 | 异常持续更新 | 异常形成时写入一次快照，后续不持续覆盖 | 确认 D4 |

## 2. Open Decisions Closed

| 决策 | 结论 | 来源 |
|---|---|---|
| D1 | 仅异常入表 | ERP-210 确认 D1 |
| D2 | 飞书字段按 ERP-210 异常跟踪口径收敛 | ERP-210 确认 D2；需求拆解第 4 条 |
| D3 | ERP 已接收或接收失败，只要形成可识别异常即写飞书；正常单据不写 | ERP-210 确认 D3 |
| D4 | 保留异常回传；删除正常链路同步；异常写入后不持续更新 | ERP-210 确认 D4 |

设计树 frontier 已为空，业务取舍均已关闭。

## 4. 多维分析

| 维度 | 结论 | 来源 |
|---|---|---|
| 完整性 | 覆盖接收、匹配、推仓、异常回传、异常入表和取消判定 | ERP-210 需求拆解第 1-5 条 |
| 清晰度 | 飞书记录范围、字段口径、写入时点和更新策略由 D1-D4 关闭 | ERP-210 确认 D1-D4 |
| 可行性 | 现有 Workflow 与样机出库聚合可复用；需新增外部接收、异常快照和取消接口 | 现状侦察表 |
| 一致性 | 新 PRD 取代既有 PRD 中“正常与异常均持续同步飞书”的口径，其他 ERP 主链路兼容 | ERP-210 确认 D1-D4；ERP-208 PRD revision 127 |
| 可测试性 | 以正常命中、未命中、推仓失败、接收失败、未出库取消、已出库拒绝取消验证 | ERP-210 需求拆解第 2-5 条 |
| 可追溯性 | 所有结论均回链需求条目或确认 D1-D4 | 本文来源列 |

## 5. 跨域影响与风险

| 域/风险 | 影响或风险 | 控制措施 | 来源 |
|---|---|---|---|
| ORD | 外部申请接收、幂等、自动办理和取消结果返回 | 订单域主责业务编排 | ERP-210 第 2、3、5 条 |
| IMS | 样机出库单、出库流水、推仓和实际出库判定 | 复用现有出库聚合 | ERP-210 第 2、3 条 |
| PLAT | Workflow 定义扩展和飞书异常快照 | 平台域提供配置与外部同步 | ERP-210 第 1、2、4 条 |
| 重复推送 | 重复建单或推仓 | 申请单号作为幂等业务键 | ERP-210 第 5 条 |
| 推仓结果未知 | 重复推仓或误判成功 | 归入异常，不按成功继续办理 | ERP-210 第 2 条；确认 D3 |
| 取消与出库并发 | 已出库后被取消 | 锁定事务内按实际出库数量判定 | ERP-210 第 3 条 |
| 异常快照不更新 | 飞书与后续办理状态不同 | 明确为异常发生时快照 | 确认 D4 |
