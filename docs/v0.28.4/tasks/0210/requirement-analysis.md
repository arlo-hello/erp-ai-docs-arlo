# ERP-210 需求分析

## 1. 需求范围

| 类型 | 范围 | 结论 | 来源 |
|---|---|---|---|
| 包含 | ERP 接收 | 接收并记录样机系统推送的全部已审批样机申请 | ERP-210 需求拆解第 2、5 条 |
| 包含 | Workflow | 新增样机出库触发器、条件和动作，接收后自动匹配 | ERP-210 需求拆解第 1、2 条 |
| 包含 | 自动推仓 | Workflow 命中后推仓；未命中或推仓异常时结束本次自动办理 | ERP-210 需求拆解第 2 条 |
| 包含 | 异常闭环 | ERP 接收申请后，Workflow 未命中或推仓异常时回传样机系统并写入一次飞书异常快照 | ERP-210 需求拆解第 2、4 条；确认 D1、D4；需求调整 2026-11-25 |
| 包含 | 取消联动 | 样机系统完成未出库校验后向 ERP 发起取消，ERP 取消关联单据链 | 当前飞书 PRD §3.5，revision 178 |
| 包含 | 编辑联动 | 样机系统完成未出库校验后向 ERP 发起编辑，ERP 先取消关联单据链 | 当前飞书 PRD §3.6，revision 178 |
| 不包含 | 样机系统内部功能 | 不描述样机系统页面、字段及审批实现 | ERP-210 范围限定 |
| 不包含 | 正常单据飞书同步 | 正常接收、命中、推仓和出库结果均不写飞书 | 确认 D1、D3、D4 |
| 不包含 | 异常持续更新 | 异常形成时写入一次快照，后续不持续覆盖 | 确认 D4 |
| 不包含 | ERP 接收失败分支 | 系统联调保证样机申请可被 ERP 接收，不设计“接收失败且可识别”业务分支，也不因此写飞书 | 需求调整 2026-11-25 |

## 2. Open Decisions Closed

| 决策 | 结论 | 来源 |
|---|---|---|
| D1 | 仅异常入表 | ERP-210 确认 D1 |
| D2 | 飞书字段按 ERP-210 异常跟踪口径收敛 | ERP-210 确认 D2；需求拆解第 4 条 |
| D3 | 已被本次需求调整部分替代：正常单据不写飞书仍有效；“接收失败写飞书”失效 | ERP-210 确认 D3；需求调整 2026-11-25 |
| D4 | 保留异常回传；删除正常链路同步；异常写入后不持续更新 | ERP-210 确认 D4 |
| D5 | 不存在样机系统推送后 ERP 接收失败且可识别的业务场景，因此无对应回传和飞书记录 | 需求调整 2026-11-25 |
| D6 | 当前飞书 PRD 为事实源；是否允许取消或编辑由样机系统校验，ERP 收到请求后取消关联单据链 | 用户确认与当前飞书 PRD §3.5、§3.6，revision 178 |

设计树 frontier 已为空，业务取舍均已关闭。

## 4. 多维分析

| 维度 | 结论 | 来源 |
|---|---|---|
| 完整性 | 覆盖接收、匹配、推仓、异常回传、异常入表、取消联动和编辑联动 | 当前飞书 PRD §1-§4，revision 178 |
| 清晰度 | 飞书只记录 Workflow 未命中和推仓异常；接收失败分支由 D5 明确排除 | ERP-210 确认 D1-D4；需求调整 D5 |
| 可行性 | 现有 Workflow 与样机出库聚合可复用；需新增外部接收、异常快照、取消联动和编辑联动接口 | 现状侦察表；当前飞书 PRD §3.5、§3.6 |
| 一致性 | 新 PRD 取代既有 PRD 中“正常与异常均持续同步飞书”的口径，其他 ERP 主链路兼容 | ERP-210 确认 D1-D4；ERP-208 PRD revision 127 |
| 可测试性 | ERP 侧验证取消请求和编辑请求均取消关联单据链；允许性校验由样机系统负责，不设计 ERP 拒绝分支 | 当前飞书 PRD §3.5、§3.6，revision 178 |
| 可追溯性 | 所有结论均回链需求条目或确认 D1-D4 | 本文来源列 |

## 5. 跨域影响与风险

| 域/风险 | 影响或风险 | 控制措施 | 来源 |
|---|---|---|---|
| ORD | 外部申请接收、幂等、自动办理、取消联动和编辑联动 | 订单域主责业务编排 | 当前飞书 PRD §3.2-§3.6 |
| IMS | 样机出库单、出库流水、推仓和关联单据链撤销 | 复用现有出库聚合 | 当前飞书 PRD §3.3、§3.5、§3.6 |
| PLAT | Workflow 定义扩展和飞书异常快照 | 平台域提供配置与外部同步 | ERP-210 第 1、2、4 条 |
| 重复推送 | 重复建单或推仓 | 申请单号作为幂等业务键 | ERP-210 第 5 条 |
| 推仓结果未知 | 重复推仓或误判成功 | 归入异常，不按成功继续办理 | ERP-210 第 2 条；确认 D3 |
| 系统间校验契约不一致 | 样机系统误把已出库申请发送为取消或编辑请求 | 联调契约明确样机系统先校验全部商品未出库；ERP 验证请求幂等并记录来源 | 当前飞书 PRD §3.5、§3.6 |
| 异常快照不更新 | 飞书与后续办理状态不同 | 明确为异常发生时快照 | 确认 D4 |

## 6. DDL 预判

| 对象 | 预判 | 说明 |
|---|---|---|
| 外部样机申请接收记录 | 新增 | 保存推送申请、幂等键、办理阶段、异常和关联单据 |
| Workflow 定义 | 扩展 | 新增样机触发器、条件属性和动作定义 |
| 样机出库单 | 复用并补充关联 | 复用外部业务单号，专用来源字段由技术方案确认 |
