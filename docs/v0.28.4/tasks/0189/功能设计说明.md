# 功能设计说明

## 需求到系统对照

| 需求 | 现状 | 结论 |
|---|---|---|
| 渠道体积重系数 | 物流渠道已有编辑表单，但无该字段 | 全新字段，复用表单 |
| 实重与总体积 | 工作流已按商品及履约数量计算 | 已有能力 |
| 计费重量 | 尚无实重与体积重取大值属性 | 新增计算属性 |
| 数值比较 | 新条件需覆盖六类比较符 | 支持大于、大于等于、小于、小于等于、等于、不等于 |
| 异常提示与快照 | 商品不存在已有异常，但缺系数和计算快照未覆盖 | 部分新增 |

## 功能清单

| 功能ID | 功能 | 规则 | 异常处理 | 来源事件 |
|---|---|---|---|---|
| FN-01 | 维护体积重系数 | 非必填；填写时为 1 至 9,999,999,999 的整数 | 非法输入不保存 | E01 |
| FN-02 | 配置计费重量条件 | 支持大于、大于等于、小于、小于等于、等于、不等于；阈值 0.00 至 99,999,999.99 | 比较符不在六类范围或阈值非法时不保存 | E02 |
| FN-03 | 计算实重 | 按 SKU 重量乘履约数量求和，定点四位 | 缺失、0、负值或非法则异常 | E03 |
| FN-04 | 计算体积重 | 总体积除以当前渠道系数，中间四位 | 任一尺寸或系数无效则异常 | E03 |
| FN-05 | 计算并比较计费重量 | 取实重、体积重较大值，四舍五入两位后比较 | 不允许以 0 降级 | E03 |
| FN-06 | 阻断并记录异常 | 停止本条自动履约动作，区分缺系数与具体 SKU 字段 | 记录失败时仍不得继续动作 | E04 |
| FN-07 | 保存执行快照 | 保存系数、实重、总体积、体积重、计费重量和比较结果 | 重试使用新一次快照，不覆盖历史 | E03、E04 |

## 页面与字段

```text
+----------------------------------------------------------+
| 编辑物流渠道                                             |
+----------------------------------------------------------+
| 渠道名称 [____________________________]                   |
| 签名服务 [请选择 v]                                      |
| 状态 [请选择 v]                                          |
| 已对接自提物流 [请选择 v]                                |
| + 体积重系数 [____________] 非必填，正整数，最多10位     |
| 后续现有字段省略展示                                     |
+----------------------------------------------------------+
```

本线框仅用于标识本次新增字段在既有表单中的上下文，不做前端页面 1:1 原型还原；线框中的前四项为现有字段，体积重系数为本次新增字段。来源：用户补充反馈（2026-11-06）。

```text
+----------------------------------------------------------+
| 编辑自动履约工作流                                       |
+----------------------------------------------------------+
| 条件字段 [max（实重，体积重） v]                         |
| 比较符   [大于/大于等于/小于/小于等于/等于/不等于 v]     |
| 阈值     [________________]  最多8位整数、2位小数         |
|                                      [取消] [保存]        |
+----------------------------------------------------------+
```

| 字段 | 类型 | 必填 | 校验 | 展示/保存 |
|---|---|---|---|---|
| 体积重系数 | 正整数 | 否 | 1 至 9,999,999,999 | 原值展示，空值保存为空 |
| 条件阈值 | 十进制 | 是 | 0.00 至 99,999,999.99，最多两位小数 | 保存两位小数 |

## 状态与权限

| 计算前提 | 条件结果 | 自动履约动作 | 历史记录 |
|---|---|---|---|
| 全部有效 | 命中 | 执行 | 成功快照 |
| 全部有效 | 未命中 | 不执行 | 未命中快照 |
| 渠道系数无效 | 不判定 | 阻断本条动作 | 缺系数异常 |
| 商品重量或尺寸无效 | 不判定 | 阻断本条动作 | 带 SKU 与字段的异常 |

权限沿用物流渠道编辑、工作流编辑、工作流历史查看权限，不新增角色。无库存守恒或 N:1 聚合变化。页面推导为 2 个编辑页面、1 个异常反馈区；关键页面线框覆盖数与推导一致。
