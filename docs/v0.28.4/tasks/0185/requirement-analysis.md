## 2. Open Decisions Closed

| 决策 | 结论 | 来源 | 影响域 |
|---|---|---|---|

| 一级分摊对象 | 由 SKU 改为产品分类；配置时无需知道订单 SKU | 2026-11-06 业务调研背景及§2.1 | 动作配置、产品分类、履约行金额 |
| 分类金额口径 | 每个分类可选人工固定值或占总申报金额百分比；同一履约动作内采用同一种一级分摊方式，避免固定值与百分比混算 | 2026-11-06 业务调研变更说明§2.1 | 动作配置、保存校验 |
| SKU 二级分摊 | 在分类行右侧单选按 pcs 均摊或按销售价格浮动分摊；运行时只处理该分类在本履约单实际出现的 SKU | 2026-11-06 业务调研变更说明§2.1.1 | 运行时计算、履约行金额 |
| 精度与尾差 | 所有履约行采用截断法，不设置尾差承接行 | 2026-11-04 对 Q3 的调整 | 计算、幂等 |
| 比例输入 | `0.1%～100.0%`，步长 `0.1%`，0 非法 | 确认 Q4 | 前后端校验 |
| 条件组合 | 复用 workflow AND/OR，不新增固定三维关系 | 已确认 Q5 | workflow |
| 条件依赖 | 物流渠道是否可选只取决于同一条件组中是否已有选值的发货仓库条件，与条件组 AND/OR 无关 | 2026-11-04 PR 纠偏说明§1 | 条件编辑器、保存校验 |
| 条件计算符号 | 物流渠道条件只允许等于和不等于，不继承其他字段可能支持的比较符号 | 2026-11-04 第三轮 PR 纠偏说明 | 条件编辑器、条件求值 |
| 页面边界 | 条件节点与履约动作节点各自独立；条件字段不得出现在履约动作线框，履约字段不得出现在条件节点线框 | 2026-11-04 第二轮 PR 纠偏说明 | workflow 编辑器 |
| 重算与冻结 | 新履约单重新计算；推仓后冻结，修改须取消并重建 | 确认 Q7 | 拆单、换仓、审计 |
| 币种 | 沿用履约行申报币种；空币种或多币种失败 | 确认 Q8 | 履约、仓库接口 |

设计树 frontier 为空。2026-11-06 变更已取代“预选 SKU 并配置占比”的旧方案：固定金额模式保存产品分类、一级分摊方式与值、SKU 二级分摊方式，不保存订单 SKU。人工固定值模式下分类值合计必须等于总申报金额；百分比模式下分类占比合计必须为 100%。运行时先得到分类金额，再按该分类实际 SKU 的 pcs 权重或“销售单价×pcs”的销售金额权重分配到 SKU，最后换算履约行申报单价并统一截断；不设置末行补差。

## 5. 影响与风险

| 风险 | 影响 | 处理 |
|---|---|---|
| 固定金额被误当 SKU 单价 | 总申报额倍增 | 动作字段明确固定金额是“履约单申报总额”，先分配分类金额，再计算 SKU 申报单价 |
| 固定值与百分比混用 | 分类金额无法守恒 | 一级分摊方式设为动作级单选；固定值合计等于总额，百分比合计等于100% |
| 销售价格为0或缺失 | 销售价格权重无法计算 | 按销售价格浮动时以“销售单价×pcs”为权重；总权重不大于0则整体失败并人工处理 |
| 全行截断产生余量 | 计算结果可能小于固定金额 | 按 Q3 调整接受截断余量；不自动补给任一履约行，测试记录截断前后差额 |
| 将仓库依赖误做成执行时序 | 扩大 workflow 引擎改造范围 | 只在同一条件组的配置与保存阶段校验“已选仓库后才可选渠道” |
| 条件字段与履约动作字段混画 | 前端错误地把两种节点实现为一个表单 | 页面推导表固定为条件节点和履约动作节点两页；分别维护字段表、按钮表与 E2E 验收 |
| 换仓保留旧渠道 | 选项与仓库不匹配 | 配置端换仓立即清空；服务端保存时复核绑定关系 |
| 拆单重复分摊 | 子单合计漂移 | 每张新履约单独立以自己的总额与数量重新计算（确认 Q7） |
| 已推仓数据被覆盖 | ERP 与仓库申报不一致 | 已推仓快照冻结；取消并重建后才能应用新规则（确认 Q7） |

## 6. 跨域与数据结论

- 订单/履约域：workflow 条件节点与履约动作节点保持独立；履约动作、拆单换仓、履约行申报值和异常处理直接受影响。
- 仓库/物流域：复用仓库—物流渠道绑定数据源；推仓接口消费冻结后的申报快照。
- 商品域：比例模式继续读取产品申报价；固定金额模式读取产品分类归属，运行时按实际 SKU 的 pcs 或销售金额权重二次分摊。
- DDL：产品方案不预设新增业务表。动作配置结构需要新增“申报方式、固定金额、分类一级分摊方式、分类分摊行、SKU 二级分摊方式”；是否落库新列由技术方案基于现有 workflow 字段存储确定。
