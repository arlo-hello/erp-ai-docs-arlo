# ERP-185 任务档案

## 需求背景

GL 区域部分目的国家存在免税政策，现有整数申报比例难以在不同 SKU 单价下稳定控制申报金额。需求要求在现有 workflow 上提高比例精度、在同组已选发货仓库后配置物流渠道条件，并支持固定金额及 SKU 固定申报占比。

## 方案概述

以 `ERP-SLICE-ORD-001` 交付两类独立节点：条件节点新增物流渠道选项并保留描述、且/或、条件组及条件行操作，物流渠道计算符号仅支持“等于（=）”和“不等于（≠）”；履约动作节点固定展示仓库、物流、条款、申报方式、签名服务、包材，并按比例申报或固定总金额切换输入区。固定总金额支持启用 SKU 模糊搜索、占比行新增/删除、所有履约行截断、异常处理、拆单换仓重算和推仓快照冻结。

## 影响范围

- 直接影响：workflow 条件配置、履约动作、履约行申报值、拆单换仓、推仓与异常处理。
- 复用能力：现有 AND/OR 条件组、仓库—物流渠道数据源、履约行 `declared_value` 与履约异常机制。
- 明确不做：目的国免税阈值主数据、自动税则判断、已推仓履约单原地改值。
