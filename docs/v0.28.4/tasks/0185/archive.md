# ERP-185 任务档案

## 需求背景

GL 区域部分目的国家存在免税政策，现有整数申报比例难以在不同 SKU 单价下稳定控制申报金额。需求要求提高比例精度，并允许按仓库、国家、物流渠道配置申报规则及固定总额。

## 方案概述

以 `ERP-SLICE-ORD-001` 交付 workflow 物流渠道条件、仓库渠道级联、比例/固定总额两种申报方式、数量占比分摊、确定性尾差、异常处理、拆单换仓重算和推仓快照冻结。

## 影响范围

- 直接影响：workflow 条件配置、履约动作、履约行申报值、拆单换仓、推仓与异常处理。
- 复用能力：现有 AND/OR 条件组、仓库—物流渠道数据源、履约行 `declared_value` 与履约异常机制。
- 明确不做：目的国免税阈值主数据、自动税则判断、已推仓履约单原地改值。
