# ERP-190 方案变更记录

## 2026-11-06 双维状态与操作边界

- 原履约单新增“组合状态”，仅为“已组合”“未组合”，并与履约状态并行。
- 原履约单列表在履约状态后一列展示组合状态；B2C 订单详情履约卡片按“组合状态-履约状态（数量）-履约单号”展示。
- 组合期间成员履约状态随组合履约单同步；解除有效组合后成员恢复未组合。
- 已组合成员禁止从原履约入口挂起、发起履约、拆分履约、合并履约、更换仓库；B2C 订单取消遇已组合成员时整单拒绝。
- B2C 订单编辑与退款在查询和提交阶段均排除已组合成员及其商品。
- 同步修订需求锚点、事件、功能、状态×操作矩阵、页面线框、接口契约与 AC-011 至 AC-013。

## 2026-11-05 PR 评审调整

- 原履约单列表沿用既有筛选条件，本需求不新增、删减或约束筛选项。
- 选择 0 张时隐藏选择计数与“组合履约”；选择 1 张时展示计数但按钮禁用；选择大于 1 张时按钮启用。
- 组合履约单列表将“批量取消”改名为“取消”，新增“取消挂起”；取消、挂起、取消挂起均支持选择一张或多张执行。
- 同步修订需求锚点、产品方案线框、按钮规则与切片 AC-001、AC-009。
