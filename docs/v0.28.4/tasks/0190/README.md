# ERP-190 任务档案

## 需求背景

Shopify 同店铺客户可能短时间连续下单，ERP 当前把多张订单分别生成履约单和出库流水并分别推仓；仓库只能人工并单。需求要求在不改变 Shopify 多原单事实的前提下，支持 ERP 组合执行，并覆盖正向、逆向和上下游联动。

## 方案概述

新增“组合履约单”作为唯一推仓主体。原 B2C 订单和原履约单继续承担订单行、退款及 Shopify 归属；组合时原子替换库存出库凭证，仓库出库后共享物理运单，各成员独立同步 Shopify。

## 影响范围

- B2C 履约列表、详情、操作与状态机。
- 库存出库流水、占用释放、仓库推送和回调。
- Shopify fulfillment 回写、异常中心和重试。
- 权限、审计、并发、功能开关和可观测性。
