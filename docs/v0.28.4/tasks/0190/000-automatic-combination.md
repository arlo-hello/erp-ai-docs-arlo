# ERP-190 自动组合补充说明

## 触发与范围

“自动组合”位于履约单列表右上角，由有权限的操作员点击触发一次批处理。系统按提交时的列表查询条件和操作权限生成跨分页候选快照，不读取当前勾选状态，也不在后台定时或无人触发执行。

## 分组与事务

系统先排除已组合及不满足基础状态的履约单，再使用既有组合限制字段的标准化值构造等价键。每个等价组至少包含两张履约单，组内按履约单号升序加锁并创建一张组合履约单；各组独立事务，单组失败不回滚其他成功组。手工组合与自动组合共享成员唯一约束和最终资格校验。

## 组合单号

组合单号格式为`{项目展示编码}{业务类型展示编码}-{商城ID}-{YYMMDD}{流水号}`。流水号每日按商城使用独立组合序列：1 至 99999 左补零为至少 5 位，从 100000 起自然扩位。Redis 原子自增负责取号，数据库全局唯一索引负责最终防重；缓存丢失或唯一冲突时从当日前缀最大流水续号并重试。
