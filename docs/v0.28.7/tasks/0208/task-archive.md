# ERP-208 任务档案

- 版本：v0.28.7
- 四位任务号：0208
- 业务目标：已过审样机申请自动进入独立样机 Workflow，规则命中且仓库受理后生成唯一 ERP 单据链并完成出库。
- 样机字段：新增非必填“物流渠道”，使用业务后续提供的独立选项，不引用 ERP 基础物流渠道。
- 唯一路径：取消“是否自动交运”和待推送人工补齐；取消动作“是否推单至仓库”，命中后默认推仓。
- 项目权限：“样机出库”触发器项目必填，候选项按当前账号 TAP 数据权限过滤，保存与发布时服务端再次校验。
- 交互分层：触发器与条件使用独立配置界面；触发器界面不内嵌条件组，条件界面沿用 ERP 现有“编辑配置”抽屉。
- 失败边界：Workflow 未命中或推仓失败不生成样机出库单、出库流水及后续自动单据，只保留接收/异常记录并同步飞书。
- WMS 边界：一张出库流水最多对应一张 WMS 物流单，不考虑分批发货。
- 外部同步：异常不回传样机系统；出库完成由 ERP 主动回传样机系统。
- 异常恢复：异常不影响样机审批；物流通过飞书查看异常并修正 Workflow，之后由样机系统重新推送已审批申请，开启新一轮完整流程，原接收记录不续跑。
- 逆向规则：审批通过后禁止编辑；仅全部商品零实发时允许取消并级联取消 ERP/WMS 链路。
- 飞书边界：本次不调整飞书表格结构。
- 开放项：样机物流渠道具体选项与稳定编码待业务确认。
- 文档：`requirement-analysis.md`、`product-plan.md`。
- 切片：ERP-SLICE-ORD-001、ERP-SLICE-IMS-001、ERP-SLICE-PLAT-001。
