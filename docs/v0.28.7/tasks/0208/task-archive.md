# ERP-208 任务档案

- 版本：v0.28.7
- 四位任务号：0208
- 业务目标：样机申请自动进入 ERP，按样机侧分流完成自动 Workflow 推仓或待推送补齐后人工推仓，并同步飞书与样机。
- 影响范围：订单域、库存域、平台集成域；复用售后 RMA 边界。
- 核心方案：ERP 单据 1:1；WMS 发货单 1:N；ERP 为办理状态权威源。
- 变更守卫：审批通过自动推送；仅全商品实发数量为 0 时允许样机侧取消或编辑；编辑先级联取消旧链路，再重新审批并推送新版本。
- Workflow：新增“样机出库”触发器与“样机出库推仓”动作；动作六字段必填，仓库联动库区/物流渠道，“是否推送至仓库”默认开启。
- 不推仓规则：Workflow 命中且开关关闭时不调用 WMS，ERP 自动置为已出库并按明细更新库存；飞书字段以“样机出库请求”表当前 48 字段为准。
- 文档：`requirement-analysis.md`、`product-plan.md`。
- 切片：ERP-SLICE-ORD-001、ERP-SLICE-IMS-001、ERP-SLICE-PLAT-001。
