# ERP-205 任务档案

- 需求版本：v0.28.7（来源：触发评论“本次需求版本为0.28.7”）
- 四位任务号：0205
- Multica Issue：ERP-205
- 切片：ERP-SLICE-PUR-001、ERP-SLICE-PUR-002、ERP-SLICE-PUR-003、ERP-SLICE-IMS-001
- 背景：业务人员通过外部 Agent 调用 ERP MCP，减少采购、发货、入库、B2B履约及三类调拨链路的人工录单。
- 方案：以用户本人ERP身份开放受控MCP能力；支持基于同一采购订单下一张或多张采购入库单创建下一层内部采购，形成可追溯的A→B→C或A→B→A链路。
- 影响：采购、B2B订单、库存、采购链路自动调拨、直接调拨、预报调拨、虚拟调拨、权限审计与财务字段继承。
- 范围边界：不提供采购审核，不一次创建完整采购计划，不新增自动化流程配置模块；支持三类独立调拨但不得绕过现有审批、库存和状态门禁。
- AI风险治理：工具分级、预览确认、确定性校验、幂等并发、额度频率、风险评分、会话隔离、提示注入防护、审计告警、熔断和灰度开放。
- 当前状态：业务决策已关闭，四个切片已达到DEFINED，待人工评审；实现切片默认进入backlog，人工改为todo后Developer才会执行。
