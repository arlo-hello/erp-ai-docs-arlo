# 采购入库与调拨配置自动化需求分析

> 需求版本：v0.28.7（来源：ERP-205 触发评论“本次需求版本为0.28.7”）
> 任务映射：`0205` ↔ `ERP-205` ↔ `ERP-SLICE-PUR-001`、`ERP-SLICE-PUR-002`、`ERP-SLICE-PUR-003`  
> 输入锚点：Issue 需求目标及条目1至14；附件《采购入库与调拨配置自动化—业务方案副本》§一至§六（下称“附件”）。

## 1. 一页结论

当前结论为**有条件可做，但不能直接进入实现**。本需求不是给既有采购自动链增加几个开关，而是新增“规则配置—流程快照—单据完结触发—动作有序执行—失败恢复”的通用编排能力。现有采购入库后内采、预报调拨和三类调拨可复用，但运行时必须隔离既有固定自动链，防止同一数量重复建单。（来源：Issue§动作语义、§流程完结节点、§现有采购自动化流程保留；附件§六“不重复办理”）

本期可先形成评审方案和候选切片；在业务确认自动匹配、分批推进、审批自动化、跨主体虚拟调拨四项口径前，切片保持 `CANDIDATE`，不得标记 `DEFINED/READY`。（来源：附件§2.1、§2.3、§六末段）

## 4. 六维分析

| 维度 | 结论 | 证据 |
|---|---|---|
| 完整性 | 配置、选择、完结触发、动作执行、版本冻结已覆盖；异常重试、取消、分批和审批边界仍缺口 | Issue§1至§14；附件§六 |
| 清晰度 | 动作字段较明确，但“发货动作”、开始节点“内采”、并行动作排序未给出完整字段与优先规则 | Issue§4、§6 |
| 可行性 | 现有系统已有内采、直接/预报/虚拟调拨及固定采购自动链，可复用单据能力；通用编排、版本、实例和幂等账本需新增 | 代码侦察：采购入库联动服务、调拨模型及三类调拨测试 |
| 一致性 | 新流程与旧自动链可能对同一入库完成事件重复消费，必须设置唯一处理权 | Issue末段；附件§六 |
| 可测试性 | 配置闭环和单动作可独立验证；多动作跨系统联调应作为 final 切片 | Issue§动作语义；附件§4.2至§4.4 |
| 可追溯性 | 当前结论逐项回链 Issue 或附件；D01至D04无确认答案 | 本文来源列 |

## 5. 代码侦察与影响面

| 能力 | 已有事实 | 产品判断 |
|---|---|---|
| Workflow | 已有命中记录模型、条件/动作命中顺序与结果记录 | 可复用画布交互和命中审计概念，不应直接假设可承载长事务单据编排 |
| 内采 | 采购入库确认后已有本地/跨系统内采创建、价格比例、异常通知与恢复命令 | 动作适配器复用，必须增加来源实例和幂等键 |
| 调拨 | 已有直接、预报、虚拟三类调拨；虚拟调拨创建即完成 | 动作适配器复用，完结判定按类型隔离 |
| 采购自动链 | 已有同主体/跨主体/中转固定链路 | 保留不改；新流程选择时建立互斥占用 |
| 前端 | 已有调拨列表、直接/预报共用表单、虚拟调拨独立表单 | 新模块可复用字段组件，不按现有页面直接拼装 |

关键风险：一是重复消费入库/调拨完成事件造成重复单据与库存；二是流程配置被编辑后历史实例漂移；三是跨系统结果未知时重试造成重复交易；四是部分商品数量被多流程并发占用。缓解方式分别为唯一业务键、版本快照、动作幂等账本与数量预占。

## 6. 跨域影响与 DDL 候选

| 域 | 影响 |
|---|---|
| PUR | 流程选择入口、内采动作、采购完成判定、旧自动链互斥 |
| IMS | 入库/出库完成事件、三类调拨动作、数量占用与库存守恒 |
| PLAT | 流程配置、负责人权限、版本、实例、节点与执行日志 |
| FIN | 收款账户、含税口径、付款类型/条件；跨主体虚拟调拨待确认 |
| PRODUCT | SKU 条件与部分商品选择，主数据只读复用 |

候选数据对象：流程、流程版本、节点、连线、条件组、条件、动作配置、运行实例、节点执行、来源明细占用。字段及索引仅为技术方案输入，不在产品阶段锁定物理表名；至少需要“来源单据+来源明细+数量”的唯一/并发保护，以及“实例+节点+尝试号”的幂等约束。
