# ERP-SLICE-IMS-001 记录单一仓库出库结果并安全取消契约

- slice_id: ERP-SLICE-IMS-001 | status: DEFINED
- business_outcome: 每张样机出库流水以唯一 WMS 物流单完成出库，并只在零实发时可取消全链路
- blocked_by: []

## 改造范围

沿用 ERP 出库流水单值 WMS 单号；删除 WMS 1:N、分批发货与多单汇总设计；增加完成状态、取消并发守卫和级联取消。

## 业务规则

1. 一张样机出库单对应一张出库流水，一张出库流水最多对应一张 WMS 物流单。
2. 不支持 WMS 分批、多单聚合或多运单汇总。
3. WMS 回调按唯一物流单号与事件号幂等，旧事件不得回退完成状态。
4. 仅当流水所有商品实发数量均为 0 时允许取消；任一商品实发大于 0 即拒绝。
5. 合法取消需取消样机接收记录、样机出库单、出库流水和未实发仓库任务。
6. 审批通过后的样机申请禁止编辑，不存在编辑后重建链路。
7. 取消与实发回调并发时锁定流水并复核实发数量。
