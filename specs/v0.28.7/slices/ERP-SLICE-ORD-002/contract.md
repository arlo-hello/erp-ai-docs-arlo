# 样机申请可自动建单推仓并形成异常闭环

- slice_id: ERP-SLICE-ORD-002
- 来源 Issue: ERP-210
- 切片类型: vertical
- 状态: DEFINED

## 业务结果

ERP 接收并记录样机申请，自动匹配 Workflow 并推仓；成功推仓并生成样机出库单后回传成功信息，Workflow 未命中或推仓异常时不回传、仅写入一次飞书快照；样机系统完成未出库校验后，ERP 按取消请求撤销关联单据链。系统联调保证不存在“推送后 ERP 接收失败且可识别”的业务分支。[来源：当前飞书 PRD §1-§4，revision 373]

## 范围

- 包含：样机触发器、八类条件、推仓动作、接收幂等、匹配推仓、成功结果回传、异常一次性快照和取消联动。
- 不包含：样机系统内部功能、正常单据飞书同步、异常快照持续更新、飞书侧重试。
- 不包含：ERP 接收失败且可识别的业务分支，以及由该分支产生的回传和飞书记录。
- 不包含：样机系统内部的未出库校验与允许/拒绝交互。
- 不包含：Workflow 未命中、推仓失败或结果未知的异常结果回传，以及编辑联动。

## 验收标准

| AC | 验收结果 | 验证方式 |
|---|---|---|
| AC-001 | 首次推送保存接收记录；相同申请单号重复推送不重复生成单据或推仓 | feature：重复请求两次，断言接收记录和单据链各一份 |
| AC-002 | 命中 Workflow 时按动作配置推仓并关联样机出库单与出库流水 | feature：mock 仓库成功响应，断言命中、推仓和单据关联 |
| AC-003 | 未命中时终止办理，不回传样机系统并新增一条飞书异常快照 | feature：构造无匹配规则，断言样机系统 mock 调用为零、飞书新增一次 |
| AC-004 | 推仓失败或结果未知时不按成功继续办理，不回传样机系统并新增一条快照 | feature：分别 mock 失败与未知，断言样机系统 mock 调用为零且飞书写入一次 |
| AC-005 | 正常接收、命中、推仓成功和出库完成均不写飞书 | feature：执行成功主链路，断言飞书 mock 调用为零 |
| AC-006 | 同一次异常不重复新增；写入后状态变化不更新原记录 | feature：重复触发并推进状态，断言飞书仅一次新增且无更新 |
| AC-007 | 成功命中、推仓并生成样机出库单后，ERP 向样机系统回传一次推仓成功信息 | feature：mock 仓库成功响应，断言单据生成后成功回传一次 |
| AC-008 | 收到样机系统取消请求后，ERP 不校验实际出库资格，直接取消未出库任务及关联单据链 | feature：mock 已通过样机系统校验的取消请求与仓库取消响应，断言无资格查询且链路取消 |
| AC-009 | Workflow 条件仅支持指定物流渠道、设备状态、活动、计划、SKU、国家、邮编、邮箱；项目仅在触发器中配置并受 TAP 权限约束 | E2E：逐类验证八类条件可配置且条件列表无项目，并以不同项目权限账号验证触发器项目选项范围和保存校验 |
| AC-010 | ERP 不接收编辑请求；异常分支不调用样机系统回传接口 | 契约测试：断言接口清单无编辑入口，异常场景回传调用为零 |
| AC-011 | 业务流程和飞书同步均不包含“ERP 接收失败且可识别”分支 | 契约测试：断言异常枚举和飞书触发条件仅包含 Workflow 未命中、推仓失败、推仓结果未知 |

## 测试边界

- 独立验证声明：是
- 使用样机系统、仓库系统和飞书 mock，可在无其他未合入切片时验证全部 AC。
- 验证顺序：Workflow 配置 → 接收幂等 → 成功主链路与成功回传 → 异常分支不回传 → 飞书快照 → 取消联动。
- 不验证样机系统、仓库系统内部页面及飞书人工编辑。
- 不模拟 ERP 接收失败业务分支；系统间传输技术故障由联调与通用基础设施测试覆盖。

## 依赖与 Mock 策略

| 依赖 | 策略 |
|---|---|
| 现有 ERP Workflow | 测试库配置触发器、条件和动作 |
| 现有样机出库能力 | 工厂数据创建并断言关联状态 |
| 样机系统 | mock 推送、成功结果接收和已完成未出库校验的取消请求；断言异常不回传 |
| 仓库系统 | mock 推仓成功、失败、结果未知和取消响应 |
| 飞书 | mock 新增快照，并断言不调用更新接口 |

## 业务不变量

1. 同一申请单号不得产生重复 ERP 单据或重复推仓。
2. 正常链路不得写飞书。
3. 同一次异常只写一条快照，写入后不持续更新。
4. ERP 只处理样机系统已完成未出库校验后发送的取消请求，不重复校验取消资格。
5. 成功结果仅在生成样机出库单并成功推仓后回传；异常结果不得回传样机系统。
6. 成功推仓后的申请不支持编辑联动。
